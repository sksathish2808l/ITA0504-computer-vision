
# Experiment 6: Image to Grayscale Conversion

## Aim
To read an image in Python and convert it to grayscale
using OpenCV.

## Libraries Used
- Python
- OpenCV
- Matplotlib

## Method
1. Read the input image using cv2.imread().
2. Convert the color image to grayscale using
   cv2.cvtColor() and cv2.COLOR_BGR2GRAY.
3. Display the original and grayscale images.
4. Save the output image.
